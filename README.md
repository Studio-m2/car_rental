# DriveLuxe — React + Tailwind Car Rental

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Included functionality

- Fully responsive navbar + mobile drawer
- Hero section with premium car visual
- Location input
- Functional pick-up and return date fields
- Date validation
- Search Cars action
- Fleet filtering by category
- Responsive car cards
- Reserve car modal
- Booking confirmation interaction
- Smooth navigation
- Tailwind CSS styling
- Lucide React icons
